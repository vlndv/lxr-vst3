# Mapping reference vectors (P2)

`harness.c` builds the expected values used by `dsp/ParamMapEnvTest.cpp` and `dsp/ParamMapMiscTest.cpp`.
It links the ORIGINAL `SlopeEg2.c`, `Decay.c` and `distortion.c`, and includes the other original functions
(`calcPitchModAmount`, `midiParser_calcDetune`, `lfo_setFreq`, `osc_recalcFreq`, `transient_setWaveform`) copied verbatim from the source
(the file was generated by a script that extracts each function, no hand copying).
`expected_output.txt` is the output from gcc x86-64.

Run from the repo root (adjust `REF`):
```
REF=ref/LXR-0.37/mainboard/LxrStm32/src
S=tests/reference/mappings/stub
for f in SlopeEg2 Decay distortion; do gcc -O0 -ffp-contract=off -I$S -I$REF/DSPAudio -I$REF/MIDI -w -c $REF/DSPAudio/$f.c -o out/$f.o; done
gcc -O0 -ffp-contract=off -I$S -I$REF/DSPAudio -I$REF/MIDI -w -o out/map_harness tests/reference/mappings/harness.c out/SlopeEg2.o out/Decay.o out/distortion.o -lm
./out/map_harness > out/map_out.txt
diff out/map_out.txt tests/reference/mappings/expected_output.txt && echo SAME
```
Note: the harness uses a synthetic note table (1000 + index) to test indexing and clamping of `osc_recalcFreq`; the real table is `data/midi_note_frequencies.bin`.
On x86 the original `lfoPhaseOffset` line is undefined at v = 127 (float 2^32 to uint32), so the harness does not print it; the test expects the ARM-style saturated value 0xFFFFFFFF.
