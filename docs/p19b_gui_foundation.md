# P19-B production GUI shell and core controls

Classification: **development PASS; direct REAPER GUI acceptance BLOCKED; P16-F release certification remains BLOCKED**.

## Baseline

The task began on `p12b-4c-fir-resampler` at local, tracking and live remote
`be35649be6ae31c07ae5cbd6dbe225a20f4d5422`. The index was empty. All 18
P19-A source-controlled files and all evidence entries matched
`out/p19a/file_inventory.json` by path, byte count and SHA-256, so the
uncommitted checkpoint was classified `ACCEPTED_INTENTIONAL_P19A_WORKTREE`.
The nine SVGs retained their certified 1280 by 800 view boxes and concept
notices. P19-A contracts passed at GCC O0/O2 and VS LLVM O0/O2 before the first
commit and again after implementation.

The firmware, iPlug2 and VST3 SDK pins remained `dee49689...`, `d54f690...`
and `3cdf9ca...`. The protected installed DLL remained
`89F6DF598EBC88F580A6013D83DA10053A177ECBBFC89CA88AC474E2C3E7FF82`; its
seven resources remained byte-identical to `data/`.

## Production shell

The initial fixed design canvas is 1280 by 800 at a configured 30 Hz graphics
idle rate. `PLUG_HOST_RESIZE` remains zero. No arbitrary resize claim is made.
The editor uses the pinned iPlug2 vector controls, Segoe UI text and deterministic
coordinates; there is no second UI framework or bitmap-scaled background.

Persistent regions contain LXR identity, current kit, selected synthesis owner,
pattern, internal/host clock mode, valid BPM, host playing/stopped validity,
sequencer state, Morph Amount and operation status. Host transport is read-only.
Invalid host tempo is displayed as unavailable rather than inferred from stale
context. Kit identity is read from the coordinated production authority on each
bounded UI refresh, including after restoration.

Exactly one of Overview, Sound, Modulation, Sequencer or Kits + Morph is visible.
View changes and the six-owner selection are transient UI state: they create no
host gestures, state serialization or Engine reset. Drum 1, Drum 2, Drum 3,
Snare, Cymbal and Hi-hat are the only synthesis owners. Closed/open hats remain
two sequencer articulations of the one Hi-hat owner.

Overview supplies the six voice levels, global decimation, sequencer enable,
clock mode, internal tempo and Morph Amount, plus shortcuts into the existing
kit and morph operations. Sound supplies one pitch, cutoff and source-grounded
wave selector for the selected owner. Modulation supplies the native 7-bit
volume-modulation toggle and one typed velocity route selector for the selected
owner. Sequencer is an explicitly incomplete status surface; no grid is
fabricated. Kits + Morph calls the existing P17-E/P17-F/P18-C operations and
file dialogs directly; parsing and transactions are not duplicated.

## Parameter and route behavior

There are 41 representative editable host bindings and no duplicate parameter
attachment. Mouse edits use iPlug2's normal begin/send/end automation path.
Wheel, keyboard and custom-selector reset paths bracket their own gestures.
Integer controls retain exact value entry and defined defaults. Host-to-GUI
readback remains the framework's parameter projection.

Firmware wave and on/off fields retain their actual 0..127 host range. The wave
selector offers the six source-defined built-in identities while preserving and
displaying a restored unsupported SD value until the user changes it. The
source on/off control writes 0 or 127 and displays its exact stored byte. The
registered 0..1 sequencer-enable parameter supplies the true Boolean case.

The reusable typed selector stores a `RouteToken16`, never a menu index. Options
are generated by `route_host::decode()` for the route's source and owner. OFF,
accepted high identities above 127 and exact host readback are supported;
reserved, unavailable and cross-owner values retain the previous accepted
selection. The complete matrix remains P19-D scope.

## Readback and real-time safety

`ReadbackAuthority` is per instance and consists of three lock-free 64-bit
atomics with an even/odd publication generation. The audio owner publishes only
tempo validity/value, transport validity/playing, active and pending pattern,
sequencer enabled/running, clock mode and internal tempo. Acquisition performs
at most four fixed copies. It has no heap allocation, mutex, wait, file I/O or
log, and never copies the pattern bank. Patch, route, kit and morph authorities
remain unchanged; Morph Amount uses host parameter 245.

The editor polls at the framework's bounded 30 Hz idle rate and invalidates a
text control only when its displayed string changes. It does not draw from the
audio thread or redraw per audio block. A one-million-iteration
publish-plus-snapshot measurement reported 5--97 ns per round trip across the
four required compiler/optimization builds; this measures the readback exchange,
not a promised visual frame rate.

Exact-DLL IAT instrumentation observed zero allocations during 4,000 processing
callbacks, a full 4,096-event callback, a 4,097-CC-plus-note overflow case and
recovery. The largest observed processing stack watermark was 20,288 bytes on a
1 MiB stack. File import correctly allocates outside processing.

## Keyboard and accessibility

Tab and Shift-Tab traverse deterministic view, owner and visible parameter
controls. Enter/Space activates navigation or opens supported parameter input;
arrows adjust one step, Page Up/Down adjust ten steps, and Home/End select
bounds. A three-pixel focus ring and custom-selector focus state provide a
visible focus indication. Stable tags, labels, tooltips, contrast and plain
operation errors are present.

The pinned custom-drawn framework still does not prove a complete native Windows
accessibility tree or full screen-reader compatibility. Mouse, keyboard, host
automation and DAW generic-parameter views are the available alternatives.
Native screen-reader and DPI visual acceptance remain P19-F gates.

## Verification

- P19-B foundation: GCC O0/O2 and VS LLVM O0/O2 PASS; five views, six owners,
  41 unique bindings, full-width routes, independent instances, coherent
  snapshots and zero measured snapshot allocations.
- Exact private DLL lifecycle: 104/0 PASS; creates a 1280 by 800 editor view,
  reports non-resizable, emits no editor-lifecycle host edit, preserves
  bit-identical audio after closure, isolates two instances and reports 26
  samples latency at 48 kHz. The pinned wrapper's advisory
  `checkSizeConstraint()` is not an acceptance signal when `canResize()` is
  false.
- Full source-built checkpoint: 42 native O0/O2 executions PASS. The private
  DLL host suites for state, audio, controller, modulation, transport,
  persistence, MIDI, kit and morph operations PASS. ControllerSyncProbe is
  1057/0; Steinberg validator is 47/47.
- Dedicated P19-A, P18-C/P18-B, P17-E/F, P16-F2, P15, velocity routing and base
  mapping regressions PASS. Original-C filter comparisons are exact for 80,000
  blocks per optimization; snare, FIR quality/latency and native synthesis pass.

The isolated Release x64/v145 candidate was built with both deployment events
disabled. Its DLL SHA-256 is
`B6BFDA4014EAE7666108C848504B3DAADB4F6433A83D936CB33DBADAF764725B`.
All seven private resources match the source assets. The protected installation
was unchanged before and after.

An isolated REAPER 7.80 profile scanned the private-only bundle and opened its
task project. The uniquely resolved `musical` window could not be acquired by
the computer-control service: both supported app selections timed out before
state or input was available. No click or key was sent. Direct view switching,
voice selection, save/reopen and visual DPI checks are therefore **BLOCKED**, not
claimed. Exact-DLL host verification and the 26-sample latency gate pass
separately.

## Deferred scope

P19-C owns the complete six-voice sound editor and layout refinement, including
correction of conceptual SVG content that extends below its certified 800-pixel
view box. P19-D owns the complete modulation and kits/morph editors; the
sequencer grid and preset browser remain later scope. P19-F owns native
accessibility, screen-reader, DPI and final graphical certification. No sample
loading, new synthesis feature, serialization field or complete editor was
added. P16-F release certification remains BLOCKED and unchanged.

Evidence is under `out/p19b/`; the primary reconciliation is
`out/p19b/verification_report.md`.
